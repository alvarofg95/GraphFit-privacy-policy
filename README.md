# Política de Privacidad de GraphFit

**Última actualización:** Mayo de 2026

> **Resumen de Privacidad:** GraphFit es una aplicación 100% offline y privada. Tus entrenamientos, rutinas y métricas corporales se almacenan exclusivamente en tu dispositivo y nunca se envían a servidores externos.

---

## 1. Información que recopilamos
GraphFit **no recopila, almacena ni transmite** información personal identificable (PII) a través de internet. Todos los datos introducidos en la aplicación (como peso, altura, registros de series y rutinas personalizadas) se guardan localmente en la base de datos interna de tu dispositivo (SQLite/Room).

## 2. Uso de los datos
Dado que los datos no abandonan tu dispositivo, la aplicación los utiliza únicamente con el propósito funcional de mostrarte tu historial de entrenamiento, tus gráficos de progreso y tus cálculos de índice de masa corporal (IMC).

## 3. Permisos de la aplicación
GraphFit requiere permisos mínimos estrictamente necesarios para su funcionamiento local:
- **Almacenamiento local:** Para guardar de forma segura tu base de datos de entrenamientos en el dispositivo.

## 4. Servicios de terceros
GraphFit no integra SDKs de análisis de terceros, herramientas de seguimiento ni servidores de telemetría que compartan tu información con anunciantes u otras entidades.

## 5. Seguridad
Almacenar tus datos de forma local en tu dispositivo garantiza que tú mantienes el control absoluto sobre tu información de salud y fitness.

## 6. Cambios en esta política
Podemos actualizar nuestra Política de Privacidad ocasionalmente. Te recomendamos revisar esta página periódicamente para cualquier cambio.
